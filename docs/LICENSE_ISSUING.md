# Pro 许可证：签发与运维

面向**你自己**（开发者）的操作手册。买家只需要「设置 → 关于 → 支持开发者 → 输入许可证」。
原理与代码见 `Sources/Suishouqian/Services/LicenseManager.swift`。

## 0. 这套机制长什么样

> **与 MIT 的关系**：本仓库以 MIT 授权，源码可自由使用、修改、再分发。
> 购买 Pro 买的是**一份离线许可证文件 + 开发者支持**，不是对 MIT 的额外限制——
> 它不增加任何限制，也不削减任何人在 MIT 下已获得的权利。
> 许可证由 Ed25519 签名离线校验，不联网、不收集数据。

```
你的私钥（本机，绝密）  ──签名──▶  许可证字符串  ──爱发电私信──▶  买家粘贴进 App
                                                                    │
                                        App 内嵌公钥 ──离线验签──────┘
```

- **零服务器成本**：不做联网校验、不做激活服务器、不收集数据。
- **买断制**：默认到期日 `2099-12-31`，等于永久。
- **不绑机器**：许可证只含邮箱，买家换 Mac 直接把同一串粘过去即可，不需要"迁移授权"。
- **取舍**：开源 App 的客户端校验防君子不防小人（改二进制就能绕过）。
  这是刻意的取舍——换来的是 0 成本 + 0 隐私风险 + 完全离线可用。

## 1. 密钥在哪，怎么备份

| 东西 | 位置 | 性质 |
|---|---|---|
| 私钥 | `~/Library/Caches/suishouqian-license/private_key.txt`（权限 600） | **绝密**。丢了 = 无法再签发任何许可证 |
| 公钥 | 仓库根 `license_public_key.txt` + 内嵌在 `LicenseManager.swift` | 公开，随仓库发布 |

**现在就去备份私钥**：复制那 44 个字符存进密码管理器（1Password / 钥匙串 / Bitwarden）。
`~/Library/Caches` 会被系统清理工具删掉，只存在那里等于没备份。

> ⚠️ **一个应用一辈子只用一把密钥。** 换公钥 = 已售出的许可证**全部作废**，
> 且老用户无法自助恢复（只能你人工重签，还得让他们先升级到新版本）。
> `license_tool.swift keygen` 因此在私钥已存在时直接拒绝执行。

## 2. 每来一单：三条命令

```bash
cd /path/to/suishouqian-xcode

# ① 签发（把邮箱换成买家付款时留的邮箱）
swift scripts/license_tool.swift issue --email buyer@example.com

# ② 输出里那一行长字符串就是许可证，完整复制，发给买家
#    自检已内置：签完立刻用公钥验一遍，验不过会直接报错而不是发出去

# ③ 想再确认一次（可选，发出去之前）
swift scripts/license_tool.swift verify '<粘贴许可证>'
```

其他选项：

```bash
# 指定到期日（默认 2099-12-31，即买断）
swift scripts/license_tool.swift issue --email a@b.com --expiry 2027-12-31

# 用非默认位置的私钥
swift scripts/license_tool.swift issue --email a@b.com --key /path/to/private_key.txt
```

给买家的话术模板：

> 感谢支持！你的 Pro 许可证（请完整复制这一整行）：
> `xxxxx.yyyyy`
> 打开随手迁 → 设置 → 关于 → 支持开发者 → 输入许可证 → 粘贴 → 激活。
> 这串许可证请自己留存，换 Mac 时直接粘到新机器即可，无需重新购买。

## 3. 常见故障

| 症状 | 原因 | 处理 |
|---|---|---|
| 买家说"许可证无效：格式错误或签名不匹配" | 复制时截断/漏了后半段 | 让买家重新完整复制；你可用 `verify` 先自己验一遍 |
| 同上，但你 `verify` 是通过的 | 买家装的版本内嵌的是**旧公钥** | 让买家升级到含当前公钥的版本 |
| 提示"已过期" | 用了真实到期日 | `issue` 时省略 `--expiry` 即为买断 |
| 日志里出现"公钥仍是占位符" | 发布包没注入公钥 | 检查 `LicenseManager.publicKeyBase64` 是否还是 `REPLACE_WITH_YOUR_PUBLIC_KEY`；`swift test` 里有用例专门拦这个 |
| 买家在非公历区域的 Mac 上激活失败 | 历史版本没锁 `en_US_POSIX` | 已修；老版本让用户升级 |

## 4. 红线

1. **私钥绝不进仓库、不进 git、不进聊天记录、不贴进 Issue。** `.gitignore` 已覆盖
   `private_key*.txt`，但真正的保障是你别把它放进来。
2. **不要用「重跑 keygen」来"重新生成密钥"**——那会让所有已售许可证作废。
3. **不要在客户端加联网校验**，除非你愿意承担服务器成本和隐私合规义务；
   当前设计的全部卖点就是"离线、0 成本、不收集数据"。

## 5. 退出 Pro（本地）

`LicenseManager.deactivate()` 清掉本地许可证。App 目前只在「关于」页展示激活状态，
没有做"退出 Pro"按钮——买断制下没必要，也避免误触。
