### 未认证期间的实际表现

未认证状态下，爱发电**不展示**主页的昵称、头像、简介与商品标题/描述。
匿名访客实际只看到一个光秃秃的 `¥29.00` 发电按钮——**看不出买的是什么**。
同时勾选了「在主页开启『电铺』标签页」，但访客侧仍无该标签。

**认证通过后可解锁：**

- 主页正常展示昵称 / 头像 / 简介
- 发布「动态」（商品可关联动态，买家**永久**访问）
- **添加自动回复 / 添加自动随机回复（适用于激活码、礼品码场景）** ← 这才是许可证自动发货的正解
- 补货 API（开发者向）
- 电铺标签页

## 3. 在认证通过之前：发货方式

自动发货不可用，只能**人工发货**。商品描述里已写明「下单后请在本商品页留言你的邮箱」，流程：

1. 收到订单通知 → 看订单留言里的邮箱
2. `swift scripts/license_tool.swift issue --email <买家邮箱>`（见 [LICENSE_ISSUING.md](LICENSE_ISSUING.md)）
3. 把许可证那一行通过爱发电**私信**发给买家
4. 提醒买家：设置 → 关于 → 支持开发者 → 输入许可证 → 激活

## 4. 收工自检（发布推广前必须过）

1. **自己买一次**：用另一个号或让朋友下单一单，走完「付款 → 收许可证 → 激活成功」全流程。
   自己没跑通就推广，等于让买家当测试。
2. **确认没有月付残留**：设置 → 赞助方案，确认订阅方案列表为空
   （只剩「自选金额赞助」，那是爱发电自带的，不是按月扣费的方案）。
3. **匿名看一遍**：无痕窗口打开主页，确认访客能看懂在卖什么（认证前大概率看不懂，见 §2）。
